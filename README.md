FC 27 AI Transfer Market Assistant & Trade Tracker ⚽📈

A desktop application designed to evaluate EA Sports FC 27 Ultimate Team market trends, analyze community leaks using Natural Language Processing (NLP), and track coin profit logic.

Built with Python, Tkinter, OpenAI GPT-4o-mini, and SQLite, this application translates qualitative social media leaks into actionable transfer market strategies while managing trade history and EA's 5% transaction tax.

🌟 Key Features

🧠 AI-Powered Leak Analysis: Utilizes LLM prompt engineering to process raw text leaks (e.g., upcoming SBCs, POTM releases, promo drops) and extract economic impact, target card ratings, ideal buy/sell windows, and risk ratings.

💰 EA Tax & Profit Calculator: Automatically factors in EA Sports' mandatory 5% transaction tax to calculate exact gross vs. net returns, ROI percentages, and break-even sell points.

📊 Local Trade History Database: Powered by SQLite, allowing users to log executed buys/sells and track cumulative coin profit over time.

🖥️ Native Desktop GUI: Built using tkinter and ttk tabs for a clean, intuitive dashboard workflow.

📦 Executable Packaging: Configured to compile into a standalone Windows .exe application via PyInstaller.
